## Trampas / gotchas
- `npx supabase db diff` genera fantasmas: `drop extension pgjwt` y recreación de 4 vistas **sin** `security_invoker` (se saltarían la RLS). Y **no emite grants**: ni por columna, ni de funciones, ni revokes sobre vistas/secuencias, ni `alter default privileges`. Se copian a mano desde `12_tekfusion_grants.sql`. Comprobar con `npx supabase test db` y un `db diff` residual. Regla en `CLAUDE.md` §4.
- Los esquemas se cargan en orden alfabético: grants y policies que usen los helpers de `11_` van en `12_` o al final de `11_`; `06_`/`07_` corren antes de que existan.
- El hook de Bash bloquea cualquier comando que mencione `.env`, incluso un `grep` en `.gitignore`; usar Read/Edit o `git show`.
- Bash interpreta backticks dentro de `node -e "..."` con comillas dobles; para scripts con backticks, archivo en el scratchpad o heredoc con `'EOF'`.
- Node resuelve `/tmp` como `C:\tmp`; usar `$TEMP`.
- `supabase test db` lee los `*.test.sql` contra la base **con seed**; cada archivo define sus helpers temporales (`pg_temp.login_as`, `exec_count`). `set role authenticated` + `reset role` entre usuarios.
- `test:unit:app` incluía el proyecto `claude` (roto); ya no. Correr los tests con `--run`; en Windows hay que mirar el código de salida, no solo el resumen.
- `handle_new_user` exige fila en `user_invitations` desde el 2.º usuario; el primer usuario queda manager por el trigger de sincronización.
