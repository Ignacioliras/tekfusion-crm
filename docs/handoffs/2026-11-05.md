## Trampas / gotchas
- `db diff` sigue trayendo fantasmas (`pgjwt` y cuatro vistas sin `security_invoker`). Cambiar el nombre de una columna de una vista exige `drop` + `create`, así que esas migraciones van a mano.
- `resetField` de react-hook-form no actúa sobre campos no registrados: para cargar datos en el formulario usar `setValue` sin `shouldDirty`.
- `toHaveValue` de vitest-browser no acepta regex: usar `expect.poll(() => el.value).toMatch(...)`.
- El 422 del TOTP venía de invalidar las consultas al confirmar: la consulta de enrolamiento volvía a enrolar. Si ya hay un factor verificado, no se enrola.
- La tarjeta del kanban se puede arrastrar recién cuando `canAccess` resuelve. En los tests hay que esperar el drag handle, no el texto.
- `sticky` no funciona dentro del layout móvil (hay un contenedor con overflow): usar `fixed bottom-14` (alto de la navegación).
- Captura de página completa sobre un diálogo modal: sale en blanco. Capturar solo el viewport.
- Caché de vitest corrupta en Windows (EPERM al renombrar, `expectTypeOf`): borrar `node_modules/.vite/vitest` y repetir.
- `ContactList.test` › "imports contacts from a dialog…" sigue intermitente: falló una vez hoy y no se investigó.
- Supabase local: la secuencia es borrar el factor TOTP de Andrea → hacer el login → enrolarse de nuevo. Con un `db reset` se borra todo.
