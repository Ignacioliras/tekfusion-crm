# 11 · Pendientes del kickoff (datos que entrega TekFusion)

Completar a medida que lleguen. Mientras un dato esté `[PENDIENTE]`, el código usa valores de configuración por defecto y datos ficticios.

## Imprescindibles para partir
- [ ] Acuerdo firmado y pago del primer 50 %.
- [ ] Ejecutivo responsable de cada línea: válvulas → `[PENDIENTE]`, tuberías → `[PENDIENTE]`, geoceldas → `[PENDIENTE]`. Suplente de cada uno.
- [ ] Número de WhatsApp corporativo `[PENDIENTE]` y teléfono donde quedará (en la oficina, cargado, con wifi). ¿Ya está en WhatsApp Business?
- [ ] Gmail de marketing: contraseña de aplicación (16 letras) para IMAP. Regla: avisar si cambian la contraseña normal.
- [ ] Casillas VíaRed por ejecutivo: correo, contraseña, servidor/puerto IMAP y SMTP. Confirmar con VíaRed: IMAP habilitado y límite de envíos por hora.
- [ ] **SPF, DKIM y DMARC de tekfusion.cl** activos (pedir a VíaRed o a quien administre el DNS). Libux verifica en mxtoolbox. Sin esto no salen seguimientos automáticos.
- [ ] Exportación del Google Sheets actual (CSV) para la migración.
- [ ] **50 correos reales de consultas, etiquetados por línea** (válvulas / tuberías / geoceldas / otra), para medir la precisión del clasificador antes de producción. Pueden ir anonimizados.

## Equipo y usuarios
- [ ] Lista completa de usuarios con rol (gerencia / ejecutivo / lector) y correo. Confirmar total de personas.
- [ ] Contraparte del proyecto: **una sola persona** que responde, aprueba en la demo del viernes y firma (por correo) el acta de aceptación semanal.
- [ ] Correo de la contraparte para la bóveda compartida (Bitwarden) y para Cloudflare Access de staging.
- [ ] Teléfono de cada ejecutivo para avisos por WhatsApp.

## Reglas
- [ ] Definición de cada estado tal como la entiende TekFusion.
- [ ] Lista de motivos de pérdida (propuesta: precio, competencia, sin respuesta, sin presupuesto, otro).
- [ ] 3–4 consultas reales de ejemplo por línea (anonimizadas) para ajustar la clasificación.
- [ ] Cadencia de seguimiento por defecto (propuesta: días 2, 5 y 10).
- [ ] Horario hábil de envío (propuesta: L–V 09:00–18:00).
- [ ] Textos de seguimiento: Libux propone, TekFusion aprueba.
- [ ] Correo de facturación para el aviso de ganado.
- [ ] Reporte semanal: día, hora y destinatarios.
